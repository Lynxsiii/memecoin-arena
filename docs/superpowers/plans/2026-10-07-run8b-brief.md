# Run 8b: best-life scoring, hourly lives, risk-taker personas, memory wipe, no buy limits

User decisions (2026-10-07, mid-run): wipe all Claude memories (new market); add two risk-taker personas; score =
best life so they keep chasing a bigger score; lives come back one per hour; NO daily buy cap and NO cooldown for
anyone (the $50 minimum buy stays); fix the watcher waking a Claude for a coin it cannot see. Restart afterwards
without a money reset (the launcher restarts without args when the python process exits).

## 1. Churn limits off (arena.py, claude_agents.py)
- Defaults become `ARENA_LLM_MAX_BUYS_PER_DAY=0` (0 = no cap) and `ARENA_LLM_BUY_COOLDOWN_MIN=0` (0 = off); keep
  `ARENA_LLM_MIN_BUY_USD=50`. The refusal code already treats 0 as disabled (verify; tests in tests/test_churn.py
  that assert the cap/cooldown must set the env/constants explicitly instead of relying on defaults).
- The brief's buy-ration sentence (`{BUY_RATION_TEXT}`) becomes, when both are 0: "Buy as often as you like; each
  buy must be at least $50." `buy_budget` in the view: drop the `buys_left_24h`/`next_buy_in_min` fields when the
  limits are off (emit `{"buys_left_24h": null, "next_buy_in_min": 0}` or omit the key entirely; pick one, keep
  tests consistent).

## 2. Score = best life (arena.py `points`, `your_score`, docstring; claude_agents.py brief; dashboard untouched)
- `points(name)` for a Claude = `max(life_pct for every life)` where a finished life's pct is
  `(end - start) / start_cash * 100` from `lives_log` and the current life's pct is
  `(equity - life_start) / start_cash * 100`, plus `runner_bonus`. Loss weights (`LOSS_WEIGHTS`) and the milestone
  bonus (`MILESTONE_BONUS`, `acct["bonus"]`) no longer count; keep the constants/env parsing so old replays import,
  but `check_milestones` must no longer add points or hearts (set `MILESTONE_PCT` default to `0` so it is off;
  document that `ARENA_MILESTONE_PCT` only matters for the legacy scoring).
- Bots keep `points == pnl_pct`.
- `your_score` adds: `best_life_pct`, `best_life_no` (which life), `this_life_pct` (exists), `leader_best_life_pct`
  (the highest `best_life_pct` among Claudes), `lives_left`, `next_life_in_min` (from §3). Remove
  `losses_count_this_life` and `next_milestone`.
- Brief "Scoring" paragraph rewritten: points = your best single life (finished or in progress) as % of the $1000
  stake, plus runner bonuses; a bust costs the life, nothing else; the scoreboard ranks by points; real P&L is shown
  separately; "Your lives are fuel: use your first life fast and aggressively to find what works, then try to beat
  your own best life."

## 3. Lives come back one per hour (arena.py)
- New `ARENA_LIFE_REGEN_MIN=60` (0 = off). Every tick, for every Claude: if `now - acct.get("life_regen_ts", run_started) >= 60 min`
  and `lives_left < self.lives`, grant one life: `acct["hearts"] += 1`, set `life_regen_ts = now`, `life_event`
  text "You got a life back (one returns every hour)", wake the agent, room post `"<name> got a life back."`.
  A Claude that is `out`: on regen, clear `out`, give a fresh `$start_cash` stake (`stakes += 1`, `cash +=
  start_cash`, `life_start = equity after the stake`), wake it with "you are back in with a fresh stake".
- `lives_info` unchanged in shape; `lives_left` already counts `hearts`. `next_life_in_min` = minutes until the next
  regen for that Claude (0 when at max lives).
- The bust text no longer mentions loss weights; it says how many lives are left and that one comes back every hour.

## 5. Memory wipe (one-off script + main.py)
- `scripts/wipe_run8_memory.py` (or a `--wipe-journals-now` flag on main.py — pick the script): backs up journals via
  `arena.backup_journals(db, "run 8b wipe")`, then `db.save_journal(name, [])` for every journal in `db.journals()`,
  and clears the `__journal__:*` state rows if journals live there. Run it while the arena is STOPPED (the controller
  stops the process, runs the script, and the launcher restarts).
- Market memory: `main.py` warm-up only loads snapshots with `ts >= db.load_state("__run_started__")` when
  `ARENA_MEMORY_FROM_RUN=1` (default 1; 0 restores the 24h warm-up). Document in main.py's help/docstring.
